# Math Quiz Game

## Introduction
Math Quiz Game is a simple Python-based game that tests basic mathematical skills. The player answers randomly generated addition and subtraction questions and receives a score at the end.
## Features
1.Three difficulty levels
2.Randomly generated questions
3.Addition and subtraction questions
4.Score calculation
5.Accuracy calculation
6.Simple command-line interface
## Requirements
Python 3 or later
No external libraries are required.
